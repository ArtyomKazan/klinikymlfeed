# Klinika YML Feed

## Технологии
- PHP 8
- 1C-Битрикс
- JavaScript и jQuery

## Правила разработки
- Разработка ведется для коробочной версии 1С-Битрикс:Управление сайтом, редакция "Старт"
- Не изменять ядро Битрикс
- Предпочитать API D7
- Сохранять совместимость со старым кодом
- Перед изменениями изучать существующую реализацию

## Работа с проектом
- Объяснять существенные изменения
- Не удалять код без необходимости
- Учитывать ранее принятые решения

## Память проекта

Файл PROJECT_CONTEXT.md содержит историю разработки,
важные технические решения и текущие задачи.

Правила:
1. При начале работы прочитай PROJECT_CONTEXT.md.
2. Учитывай содержащуюся в нём информацию.
3. После завершения каждой задачи обновляй PROJECT_CONTEXT.md.
4. Записывай:
   - Что было реализовано.
   - Какие файлы изменены.
   - Какие архитектурные решения приняты.
   - Какие задачи остались незавершёнными.
5. Не удаляй ранее принятые важные решения.
6. Не записывай пароли, токены и конфиденциальные данные.
7. Перед завершением задачи обязательно обнови
   PROJECT_CONTEXT.md, даже если пользователь
   отдельно об этом не просил.
